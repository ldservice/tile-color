# Конфигуратор фасада — трафаретный кирпич

Одноэкранный mobile-first конфигуратор: выбор формы кладки, цвета кирпича и цвета шва с мгновенным превью на Canvas. Без сборки и зависимостей — три файла: `index.html`, `style.css`, `app.js`.

## Запуск локально

Любой статический сервер из корня папки, например:

```bash
npx --yes serve -l 5173 .
```

Открыть <http://localhost:5173>.

## Деплой на GitHub Pages

1. Создайте пустой репозиторий на GitHub (например `tile-color`).
2. В этой папке:

   ```bash
   git remote add origin https://github.com/<user>/tile-color.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Workflow `.github/workflows/pages.yml` соберёт и опубликует сайт при каждом push в `main`.
   Ссылка: `https://<user>.github.io/tile-color/`.

## Подключение как Telegram Mini App

1. В [@BotFather](https://t.me/BotFather): `/newapp` → выбрать бота → указать URL страницы с GitHub Pages.
   Или `/mybots` → бот → **Bot Settings → Menu Button** → указать тот же URL.
2. Страница сама определяет запуск внутри Telegram: разворачивается на весь экран, берёт цвета темы, даёт вибро-отклик при выборе.
3. Вне Telegram работает как обычный сайт.

## Режим «Фото стены»

По умолчанию превью показывает реальные фото стен (`assets/house1.jpg … house3.jpg`, уменьшенные, без EXIF). Лента над превью переключает между тремя снимками, переключатель «Схема кладки» показывает чистую кладку крупным планом.

Стены на фото сняты под углом (перспектива), поэтому кладка не накладывается сверху, а **перекрашивается реальная стена**: сохраняются её геометрия, фактура, перспектива и тени, меняются только цвет тела кирпича и цвет шва. Это выглядит естественно на любом ракурсе, но выбор «формы кладки» на фото не влияет (форма видна в режиме «Схема»).

Как это работает (`app.js`, массив `PHOTOS`):
- **Маска стены** — ручные полигоны зон (`regions`) минус исключения (`holes`: окна, цоколь, красный кирпич), плюс мягкий цветовой фильтр (`key`: `chromaMax`, `lumMin`, `lumMax`) — отсекает зелень, красный кирпич, крышу.
- **Разделение тела и шва** — по локальной яркости: тело кирпича светлее локального среднего, шов темнее (радиус `avgFrac`, ширина перехода `tDelta`).
- **Перекраска с сохранением яркости** — для каждого пикселя `цвет = цвет_кирпича · a + цвет_шва · b`, где `a`,`b` учитывают яркость исходного пикселя. Тени и засветы остаются на месте.

Чтобы заменить фото или добавить новое: положите файл в `assets/`, добавьте элемент в `PHOTOS`, откройте страницу и в консоли вызовите `facade.photoDebug(true)` — маска активного фото подсветится красным. Правьте поля активного фото (например `facade.active().conf.regions`) и вызывайте `facade.rebuild()`, затем перенесите подобранные значения в `app.js`.

## Экспорт картинки

Кнопка «Сохранить картинку» формирует PNG 1600×1000 с подписью выбранных цветов (RAL/NCS).
На смартфоне открывается системное меню «Поделиться» (Web Share API); если оно недоступно — показывается картинка с кнопкой «Скачать PNG» и подсказкой сохранить долгим нажатием.

Внутри Telegram Web Share недоступен, а скачивание blob-файлов встроенный WebView блокирует. Поэтому из Telegram кнопка открывает эту же страницу во внешнем браузере со ссылкой вида `?mode=photo&photo=ph1&brick=terracotta&joint=cement&export=1`: там сразу показывается готовая картинка и кнопка «Сохранить / Поделиться», которая вызывает системное меню. Такую ссылку можно и просто отправить кому-то: она откроет конфигуратор с нужным сочетанием.

## Палитра

Цвета кирпича и шва заданы в `app.js` (`BRICK_COLORS`, `JOINT_COLORS`), паттерны кладки — в `PATTERNS` (размер кирпича и шва в мм, смещение ряда, флаг «состаренный»).
